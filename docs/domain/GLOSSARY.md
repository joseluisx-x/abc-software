# Glosario

| Término | Definición de trabajo |
|---|---|
| CPE | Comprobante de pago electrónico emitido bajo el sistema y perfil SUNAT aplicable. |
| CDR | Constancia/resultado de recepción asociado a un documento o envío; formato y códigos según canal vigente. |
| OSE | Operador de Servicios Electrónicos autorizado que puede prestar servicios de recepción/validación en el sistema aplicable. |
| SUNAT | Superintendencia Nacional de Aduanas y de Administración Tributaria del Perú. |
| UBL | Universal Business Language; vocabulario de documentos comerciales estandarizados por OASIS. |
| XSD | XML Schema Definition; define estructura, tipos y cardinalidades del XML, no todas las reglas legales. |
| IGV | Impuesto General a las Ventas; tasa y supuestos aplicables se validan con texto vigente. |
| ISC | Impuesto Selectivo al Consumo; sujeto a bienes, sistema y parámetros legales. |
| ICBPER | Impuesto al consumo de las bolsas de plástico, conforme a Ley 30884 y modificatorias. |
| RUC | Registro Único de Contribuyentes. El checksum local no acredita vigencia registral. |
| CPE firmado | XML sobre el que se aplica un perfil de firma digital aceptado; los detalles del perfil requieren verificación. |
| Idempotencia | Propiedad que permite repetir una solicitud sin duplicar el efecto lógico de negocio. |
| Cuarentena | Área de staging para filas legadas ambiguas o inválidas, sin incorporarlas automáticamente al dominio definitivo. |
| ADR | Architecture Decision Record: registro breve del contexto, decisión, alternativas y consecuencias arquitectónicas. |
| POR VERIFICAR | Marca obligatoria para una regla, código, versión o mapeo que aún no está sustentado por fuente oficial confirmada. |
